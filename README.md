# Mini Projects

A collection of small programming, data science, and machine learning projects built while learning Python, Java, C, web development, and applied ML.

## Included Projects

### Java — Bank Management System

A console-based banking application demonstrating object-oriented programming with:

- Account creation
- Deposit
- Withdrawal
- Balance checking
- Account lookup
- Java collections and classes

Entry point:

```text
BankManagementSystem.java
```

### Python — Calculator & Area Utility

A menu-driven Python program containing:

- Addition
- Subtraction
- Multiplication
- Division
- Area of circle
- Area of rectangle
- Area of triangle
- Area of square

Entry point:

```text
Calculator.py
```

### RNN Sentiment Analysis

A Jupyter notebook exploring recurrent neural networks for sentiment analysis.

```text
RNN_for_SentimentAnalysis.ipynb
```

### Transformer Mini Project

A notebook containing a summarized Transformer-focused mini project.

```text
summerized_Transformer_Min_Project.ipynb
```

### Other Practice Projects

The repository also contains a C-based billing project, an HTML calculator, and a Python hotel-management testing/project file.
